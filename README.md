# One Word, First Thought

One word, first thought: this builder emits the single word and proves it clears the 24-character single-word gate. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
